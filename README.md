# 道が町を作る — Roads Build Towns

一人称視点で街道を整備する、物流シミュレーションのプロトタイプ。
TypeScript + three.js、外部ゲームエンジンなし。

谷には二つの村がある。**麦谷の農村**は食料を作れるが工具がない。
**鉄尾根の鉱山村**は鉄鉱石の上に座っているが、食べる物がなく鍛冶場が止まっている。
川は徒歩の運搬役なら浅瀬を渡れるが、荷車は一台も通さない。

検証したい瞬間はひとつだけ：

> 橋を架けて初めて荷車が通り、鉱山村へ食料が届き、止まっていた鍛冶場が動き、
> 農村に鉄製農具が返ってくる。

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # ヘッドレスのシミュレーションテスト
npm run build      # 型チェック + 本番ビルド
```

## 操作

| キー | 動作 |
| --- | --- |
| `W` `A` `S` `D` / `Shift` | 移動 / 走る |
| マウス | 視点（クリックでポインタロック） |
| `1` 調べる | 荷車・建物・道・工事現場に照準を合わせると、その中身と理由が出る |
| `2` 測量 | 視線の先の標高・勾配・地面・水深を読む |
| `3` 杭打ち | 左クリックで杭、`Q`/`E` で道路規格、`Enter` で着工、右クリック/`Backspace` で1本戻す、`X` で破棄 |
| `4` 施工 | 工事現場の先端で左クリック長押し。現場がなければ足元の傷んだ道を補修する |
| `5` 建てる | 見張り台・宿場・倉庫の建設地を決める（`Q`/`E` で切替） |
| `Space` / `[` `]` | 一時停止 / 速度（1・2・4・8・16倍） |
| `F5` / `F9` | 保存 / 読み込み |
| `Esc` | 中断（時間も止まる）。ウィンドウのフォーカスが外れただけでは止まらない |

重い機械では `?quality=low` を付けて開くと、草と作物の描画を省いて軽くなる。

## 基本ループ

1. **不足を見つける** — HUD に村の在庫と、止まっている建物とその理由が出る
2. **経路を調べる** — 測量ツールで勾配と川幅を測る。直線の東斜面は 40% の壁、北には 7% の自然の峠がある
3. **杭を打つ** — 杭と杭のあいだは一定勾配。切土・盛土・橋の支間・資材・工数がその場で出る
4. **施工する** — 資材は物流に乗って現場まで運ばれる。プレイヤーも村の作業班と一緒に働ける
5. **流れはじめる** — 荷車が走り、鍛冶場が動き、工具が返る
6. **新しい問題が出る** — 雨で土道がぬかるみ、交通量が増えると盗賊が目をつける

## 道に持たせた意味

- **物流** — 物資は瞬間移動しない。必ず誰かが運ぶ
- **勾配** — 積んだ荷車は 10%、空荷で 16%、徒歩は 32% まで。32% の道を作ることはできるが、荷物は登らない
- **路面** — 土・砂利・石畳・木橋・石橋。速度、積載上限、雨への強さ、摩耗速度がそれぞれ違う
- **雨と泥** — 土道は雨で速度が落ち、石畳はほとんど変わらない。ぬかるむと、遠回りの砂利道のほうが速くなる
- **摩耗と補修** — 通行量で路面が荒れる。濡れているほど早く傷む。村はゆっくり直し、プレイヤーは手で直せる
- **危険** — 交通量が閾値を超えると盗賊が動きはじめる。夜と、野営地の近くと、誰も見ていない場所が危ない。見張り台と宿場が効く

## 見て分かること

村人の頭上には、いま何をしているか（`食料 2箱`、`施工中`、`足止め`）が出る。
麦畑は畝が立ち、森は塊で生え、川は水深で色が変わる。道を敷いた区画の草木は消える。

## すべての遅れに理由がある

荷車に照準を合わせると、こう出る：

```
荷車                     輸送中
麦谷の農村 → 鉄尾根の鉱山村
積荷   食料 14 箱   140 / 180 kg
所要   約 4時間20分
経路：徒歩の最短路より 41分 遅いが、積荷を運べるのはこの道だけ
遅延要因：麦谷の農村付近のぬかるみ
```

運べない荷は消えるのではなく、理由付きで HUD の「滞っている輸送」に残る。

## 構成

シミュレーションは three.js にも DOM にも触れない。描画層が状態を読んで描くだけなので、
世界全体をヘッドレスで決定論的に進められる。乱数は種付きの PRNG に統一してある。

```
src/
  core/     時計・乱数・イベントログ
  world/    ハイトフィールド、地形生成、タイル格子、レイキャスト
  roads/    道路規格、施工可能性（切土盛土・橋・工数）、工事現場、経路探索、摩耗
  sim/      資源・集落・生産・車両・エージェント・物流・天候・盗賊・保存
  render/   地形メッシュ、道路と橋、建物、エージェント、測量マーカー、雨
  player/   一人称コントローラ、ツール、ピッキング
  ui/       HUD、建設パネル、インスペクタ、日本語文言
tests/      地形・道路・経路探索・生産・物流・天候・盗賊・保存・シナリオ
```

テストは仕様として書いてある。とくに `tests/scenario.test.ts` は、
測量した経路を実際に敷いて「工具が農村に返ってくる」ところまでを検証し、
道を作らない対照ケースでは返ってこないことを確認する。

## まだ入っていないもの

- 鉄道（`TransportMode` を差し替えれば載る形にはしてある）
- 踏み跡の自然発生（`trample` フィールドだけ用意済み）
- トンネル、関所の通行料、港町・森の集落・巡礼地、より広い世界
